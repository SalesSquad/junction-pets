# Architecture

Source of truth for this product is the README (pipeline, panel, measurements) and `docs/`.
Summary: find the provision (registry keywords, Exa on official domains, on-device semantic catalog) ->
official point-in-time text (eCFR, legislation.gov.uk, EUR-Lex) -> clause outline -> code rules out tiers ->
panel of judges (TypeSafe Jev, OpenAI Luna, NVIDIA Nemotron; Gemma 4 E2B + LoRA advises, decides alone in private mode) -> signed Warrant.
Exa: provision search, announced changes, next steps, news bounded to the event date, general butler.
Reuses the `junction.exa` companion (`pets/exa/`) unchanged; no copy of it here.
