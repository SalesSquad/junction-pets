## Cascade recalibration (validation only)

Rule: A note is pre-filled for one-click confirmation only when the code-resolved Gemma answer and the Nemotron v3 answer agree exactly (and, for the threshold signals, its score is at or above the validation threshold). Otherwise it needs editing. A person confirms every note. Thresholds: largest validation coverage among agreement-gated configurations with validation error <= 5% and >= 20 accepted notes; ties: agreement alone first, then the 270M model. Leak guard: scribe/v3/cascade.py assert_validation_only() runs inside select_threshold(); every test and stress id is passed as forbidden. Gemma answers: batched MLX outputs (scribe/v4/binfer.py) on validation, test and stress, so thresholds and scores come from one engine. Error target 5% on validation, at least 20 accepted notes.

## Inference engine

Single-sequence MLX decoding ran several times slower than in step 3, under GPU contention from another project's job (speeds in `runs/laneA-step3.jsonl` and `runs/laneA-step8.jsonl`), too slow to finish. Test and stress outputs therefore come from batched greedy decoding (`scribe/v4/binfer.py`, mlx_lm BatchGenerator) with the same model, adapter, prompt, stop tokens and token limit. Before any test or stress output was read, the batched engine re-ran the 310 validation notes:

- A-270m-abs: same resolved prediction on 308/310 notes, same raw text on 243/310; exact 293 single vs 294 batched.
- B-270m-expr-aug: same resolved prediction on 309/310 notes, same raw text on 309/310; exact 290 single vs 291 batched.
- C-1b-expr-aug: same resolved prediction on 310/310 notes, same raw text on 310/310; exact 304 single vs 304 batched.
- Arm A's stress outputs mix engines (mlx-single: 31, mlx-batch32: 277): the single-sequence run was stopped for speed, no score had been read, and the remaining notes were generated batched, so no stress note was generated twice.

## Limits

- SYNTHETIC notes from two writer models; the stress notes all come from Nemotron, which also wrote most training notes, so only the phrasing is new, not the writing style.
- The Nemotron reader wrote the stress notes it reads here, so its stress score is optimistic.
- The test set had been read in earlier work; its numbers are post hoc. Validation selected the arms; the stress set is the only fresh, frozen set.
- The cascade thresholds rest on 310 validation notes; with a 5% target, one error moves the observed rate by about 0.3 points at full coverage.
- Finnish only. No Swedish slice was built.
- Interval error uses the nearest predicted date of each type, which is optimistic when a system outputs the same type twice.
