## Protocol

- steps: 324
- effective batch: 16
- seed: 20261114
- selection metric: note-level exact match on the validation notes (all available writers pooled)
- size rule: highest; smaller size if within 0.03 and McNemar p >= 0.05
- arm rule: replace the control only if better with McNemar p < 0.05 (unadjusted)
- decoding rule: constrained only if strictly higher validation exact match
- budget claim order: A sizes small to large, A extras, B arms in listed order, C format, C data
- final phase sacrifice order: constrained-decoding check, version-1 recipe, zero-shot base

## Notes and limits

- the version-1 recipe was run on 270m, not on 4b as in version 1 (that size was not measured in this session or did not fit the budget)
- One seed per run. With a few hundred validation notes a difference of a few points is within noise; this is why a change replaces the control only on a paired test.
- Labels come from a synthetic generator checked by models, not by clinicians; all figures are relative to those labels.
- Risk-control thresholds hold for notes exchangeable with the calibration notes. Real clinical notes are not.
