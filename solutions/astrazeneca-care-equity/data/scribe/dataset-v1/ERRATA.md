# Errata for SAMA pathway scribe dataset v1

SYNTHETIC ONLY. Written by `scribe/post_eval.py` from the dataset files; the counts are computed, not typed.
The dataset is left as built: an adapter was trained and evaluated on exactly these files.

1. **Pathway order.** The card says the event types come from `DATA_COLLECTION.md`. The sampler (`scribe/sample.py`) uses an older order, which puts `SPECIALIST_VISIT` before `DIAGNOSIS`; `SPECIALIST_VISIT` before `MDT_DECISION`. Against the documented order (`SYMPTOM_ONSET_REPORTED <= FIRST_CONTACT <= PHYSICIAN_ASSESSMENT <= REFERRAL_SENT <= REFERRAL_RECEIVED <= DIAGNOSIS <= MDT_DECISION <= SPECIALIST_VISIT <= TREATMENT_START`) 313 of 2466 accepted episodes contain a reversed pair: 211 of 1716 training, 42 of 250 validation, 60 of 500 test. Run on the ground truth, `eventlog/validate.py` flags 313 of 2466 accepted episodes (the same episodes), and in its strict mode for simulator output it rejects every split file.
2. **Split by route plus events.** The split hash includes the entry route, so 7 test note(s) and 1 validation note(s) have exactly the event list of a training note with another route. No id, target or note text occurs in more than one split.
3. **De-duplication.** The first cached row of an id was kept whatever its verdict. Of 20 ids that occur more than once, 6 had a rejected first row and an accepted later one (the accepted note was dropped and the id filed under rejected), and in 6 a second accepted note was dropped.
4. **Cost field.** `typesafe_cost_usd` (0.287565516) under "Measured" is computed, not billed: 6,846,798 tokens x USD 0.042 per million tokens. Price source: the project owner's stated price (scribe/README.md); no invoice was read.
5. **Verifier version.** All 7,194 verifier calls of the dataset build requested the alias `jev-latest` and logged only the alias, so the version it resolved to was not captured. Same-day records elsewhere: data/claim-check/eval-v1.json recorded jev-1.14.0 at 2026-11-14T14:57:26.627Z; data/narratives/fi-v1.json recorded jev-1.14.0 at 2026-11-14T15:08:35.600Z. Both are before the first verifier call of the dataset build (2026-11-14T15:51:56.637512+00:00); that the build resolved to the same version is likely but was not recorded.
6. **Teacher.** Model id `nemotron-3.5-super-vl`; endpoint host `containers.datacrunch.io` (recorded by the integrator; not in runs/scribe.jsonl); OpenAI-compatible endpoint of the Verda inference service; the base URL came from the environment and is not in the run log; GET /models discovery in data/scribe/models.json. Version: not logged: each teacher call records the model id only. Terms: not recorded.

"Labels are exact by construction" holds for the sampled tuple only. Whether a note states exactly those events is what the verifier estimates, and the card's audit warning (a stricter pass disagreed with 43 of 60 accepted notes) still stands.
