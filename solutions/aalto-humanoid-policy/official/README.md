The harness checks Git HEAD, tracked upstream package bytes and unexpected
import sources, then checks selected-interpreter official imports. It uses the
actual upstream replay through an isolated Python bootstrap with the verified
checkout as the sole explicit `PYTHONPATH` root; it implements no wire protocol.

Choose an unused output filename each time; creation is exclusive before any
replay. Counts are bounded to 2–200 (100 for the held-out comparison); only
`ws://127.0.0.1:PORT` and `ws://localhost:PORT` are accepted, without credentials,
paths or queries. The subprocess has a 60-second wall limit and 64 KiB combined
output limit. Exactly one literal dictionary is accepted; duplicate/unknown keys,
bool-as-number, nonfinite numbers, unexpected logs and inconsistent results fail
closed. Success requires official exit 0, `calls == ticks == requested count`,
`min_hz == 27`, `command_hz >= 27`, empty errors, `n_errors == 0` and literal
`pass == True`, with no threshold overrides. The receipt records exact command,
source hashes, timestamps and parsed official metrics; raw stdout/stderr is not
stored (only its digest), to avoid retaining incidental secrets. Exit 2 means
rejected/blocked, never a qualification pass. Ordinary parser errors use argparse.
