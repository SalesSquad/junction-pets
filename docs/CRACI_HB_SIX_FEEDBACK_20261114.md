## Six error-driven corrective stages *inside each CRACI fold*

Each job fits *only* to known train5/9 object labels using frozen public numerical Apple Vision revision2 768D features plus 48 color features. It runs six sequential candidates, with a previous-champion feedback rule that selects a new policy only if it increases correctly accepted known examples while **never increasing wrong acceptance above the previous champion OR calibrated baseline** and never exceeding the unchanged empirical 5% development cap. The six predeclared stages are: (1) class prototypes cosine/temperature25 with train-only similarity quantile12; (2) more conservative temp50/quantile25; (3) broader temp10/quantile3; (4) train-only 16D PCA ridge logistic; (5) prototype/color consensus; (6) prototype/PCA dual-agreement abstention. Every stage retains its error counts, previous risk budget, whether it changed the champion and which candidate won. No training API, GPU or foundation-model reweighting; this is actual CPU supervised model fitting and risk-feedback selection, not an LLM claim.

After all **six stages are frozen**, the job opens its **eight still-withheld frame groups from scene10 exactly once** for an *internal development* result. Six jobs cover six disjoint DEV folds, resulting in up to 36 stage-level model comparisons and six disjoint internal development results. These 6 DEV folds share one source physical scene and are cross-validation **not** six independent device qualifications or a blind new dataset. No fold result can authorize model promotion, real Meta glasses detection, parent/child identity, tool permission or production deployment. Negative science is saved; technical execution can be green even if no credible model improvement.
