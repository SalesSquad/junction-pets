## Existing additional support workflows

### 1. Scope a small prototype

Input: maker idea and available parts. Deliver: prototype outline.

Clarify the intended behavior and exact parts. Keep the first milestone observable and reversible. List missing component specifications before suggesting connections.

Example request: “Help me scope a small sensor-and-light learning project using only documented low-voltage components.”

### 2. Review a parts list

Input: component names and documentation. Deliver: compatibility questions.

Check documented power, logic levels, connectors and mounting constraints. Mark unknowns rather than inventing pin mappings or ordering parts.

Example request: “Review this parts list and tell me which voltage, interface and mechanical details need checking.”

### 3. Plan a learning sequence

Input: project goal and experience level. Deliver: learning steps and checks.

Sequence sensing, logic, output and integration. Give a check for each step and distinguish a suggested experiment from verified hardware behavior.

Example request: “Create a learning sequence for my first modular robot project, starting with one safe subsystem.”
