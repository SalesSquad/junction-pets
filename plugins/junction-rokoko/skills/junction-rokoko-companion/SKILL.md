## Useful workflows

### 1. Map a capture pipeline

Input: capture setup and target application. Deliver: pipeline map and compatibility questions.

Identify capture method, cleanup, skeleton mapping, target application and export format. Flag device- and version-specific details for documentation checks.

Example request: “Help plan a Rokoko motion-capture workflow for a short character animation, from capture to export.”

### 2. Review retargeting symptoms

Input: clip metadata and described symptoms. Deliver: diagnostic checklist.

Distinguish capture quality, root motion, scale, rig mapping and contact constraints. Treat each as a hypothesis until the user provides actual observations.

Example request: “My retargeted character's feet slide. What measurements and setup details should I inspect first?”

### 3. Prepare a capture session

Input: scene goal and setup constraints. Deliver: capture and export checklist.

Include consent for performers, calibration, a short reference take, file naming and export validation. Do not state that calibration or capture has occurred.

Example request: “Create a capture checklist for a short demo with repeatable calibration and export checks.”
