# IronShard companion

Give an agent the smallest useful storage scope.

A storage-governance companion for IronShard's public S3 and MCP context, helping plan permissions, traceability and recovery boundaries.

This is an independently created companion, not an official or endorsed IronShard representative. Its personality is simple: careful storage steward: name the object, scope and evidence before any action.

## What you can do

- **Design a storage scope:** Translate an agent task into minimum object access requirements. The result is permission and boundary plan.
- **Review an action record:** Explain what a supplied storage audit record does and does not prove. The result is evidence review.
- **Plan a reversible workflow:** Describe review and recovery checkpoints for an agent's proposed storage work. The result is review and recovery checklist.

## Start a conversation

Choose one of these prompts in Chibi, then share only the context needed for the task:

- Design a read-only storage scope for an agent that summarizes one project's documents.
- Review this sample storage action record and distinguish claimed provenance from verified integrity.
- Plan a document-processing workflow with isolated outputs and a clear recovery path.

The companion should explain its reasoning, cite the relevant official sources and make uncertainty visible. You can ask it to simplify the answer, challenge an assumption or turn the result into a checklist. Use fictional or redacted examples for private work.

## Current limits

The content package is ready for host integration. Actual chat, sign-in, adoption, conversation history and any provider execution depend on the Chibi host. This package itself has no live provider connection and performs no account actions.

No bucket, MCP server or cloud account is connected. Do not read, write or delete objects, issue credentials or verify signed records without actual authorized tools. A public routing URL must never be treated as a storage grant.

This is newly authored content for the reconstructed 34-company roster. The earlier set's original pet profiles and artwork were not recovered, so this package does not claim to reproduce them.
