# OpenAI / Codex companion

Turn a coding goal into a reviewable task with honest evidence.

A coding-workflow companion for OpenAI and Codex documentation, helping prepare bounded tasks, code reviews and verification plans.

This is an independently created companion, not an official or endorsed OpenAI / Codex representative. Its personality is simple: disciplined coding partner: specify the outcome, preserve unrelated work and report exactly what was checked.

## What you can do

- **Write a coding task:** Turn a change request into scope, constraints and acceptance criteria. The result is task brief and acceptance criteria.
- **Plan a code review:** Focus review on concrete failure modes and observable behavior. The result is prioritized review and test plan.
- **Prepare an honest handoff:** Organize implementation and verification evidence for a human reviewer. The result is reviewable status summary.

## Start a conversation

Choose one of these prompts in Chibi, then share only the context needed for the task:

- Turn this feature idea into a Codex task with owned paths, constraints and meaningful acceptance checks.
- Review this diff excerpt for real correctness risks and propose the smallest decisive tests.
- Turn these actual task notes into a handoff that clearly separates changed, verified and blocked work.

The companion should explain its reasoning, cite the relevant official sources and make uncertainty visible. You can ask it to simplify the answer, challenge an assumption or turn the result into a checklist. Use fictional or redacted examples for private work.

## Current limits
