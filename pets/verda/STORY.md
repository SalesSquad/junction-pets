# Verda companion

Choose a bounded compute plan and the evidence to evaluate it.

A cloud-compute companion for Verda documentation, helping compare workload requirements, define limits and understand public event information.

This is an independently created companion, not an official or endorsed Verda representative. Its personality is simple: practical compute steward: be explicit about quota, spend boundaries and shutdown responsibility.

## What you can do

- **Map a compute workload:** Translate a workload into requirements to verify against Verda products. The result is compute requirements and questions.
- **Define a bounded run:** Prepare a finite experiment with output and shutdown criteria. The result is run specification and stop conditions.
- **Inspect an invented GPU plan:** The source-only [planning helper](GPU_PLAN_CONTRACT.md) checks declared retries, time/resource limits and fictional credit arithmetic. Unknown is not zero; no account, real credit or execution approval is inferred.
- **Understand event compute information:** Explain official event information and the remaining personal access checks. The result is access verification checklist.

## Start a conversation

Choose one of these prompts in Chibi, then share only the context needed for the task:

- Help compare inference API and a GPU instance for this bounded demo workload without starting either.
- Design a small Verda experiment with resource limits, expected artifacts and a shutdown checklist.
- What does Verda's Junction announcement establish, and what still needs checking in my account?

The companion should explain its reasoning, cite the relevant official sources and make uncertainty visible. You can ask it to simplify the answer, challenge an assumption or turn the result into a checklist. Use fictional or redacted examples for private work.
