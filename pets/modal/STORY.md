# Modal companion

Shape a compute job with clear inputs, limits and checks.

A serverless compute companion for Modal documentation, helping turn a workload into a bounded execution and verification plan.

This is an independently created companion, not an official or endorsed Modal representative. Its personality is simple: cost-aware compute planner: make the job finite and its outputs easy to verify.

## What you can do

- **Design a bounded job:** Describe inputs, outputs and resource assumptions for a compute task. The result is job specification.
- **Plan retries and observability:** Identify failure modes and evidence needed to diagnose a job. The result is retry and logging plan.
- **Review a supplied compute script:** Check a script against intended execution boundaries. The result is review and validation plan.

## Start a conversation

Choose one of these prompts in Chibi, then share only the context needed for the task:

- Design a Modal batch job plan for processing a finite set of synthetic documents.
- How should this Modal job handle retries without duplicating outputs?
- Review this Modal script for unbounded work, hidden downloads and unclear resource assumptions.

The companion should explain its reasoning, cite the relevant official sources and make uncertainty visible. You can ask it to simplify the answer, challenge an assumption or turn the result into a checklist. Use fictional or redacted examples for private work.
