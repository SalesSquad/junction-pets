# Adopt in the next project

1. Install a pinned local archive or vendor the standalone package with its provenance.
2. Admit actual bytes through a trusted adapter. Use a separately configured expected hash when
   available. Keep private inputs on the authorized host and choose storage explicitly.
3. Run a supported method with explicit parameters; distinguish source observation, calculation,
   cross-checks, human corrections and unavailable evidence in the UI.
4. Resolve every citation from the current dataset. Do not accept a model's invented excerpt or box.
5. Replay imported packets from raw bytes. Preserve stale review as history and request a new
   review when the source/extraction/result changes.
6. Freeze independently authored reference cases before tuning; report correctness, coverage,
   refusals, evidence and costs separately. This pilot's toy suite qualifies mechanics only.

## Existing systems

**Stoa:** completed reference. The package does not import its server/UI/filesystem. Explicit
v1 migration reads a packet and original DXF; it starts fresh review and retains old history.

**Valmet/ECRE:** a future adapter should retain exact source memberships, units and frame
provenance. No PLY/3D calibration adapter or private industrial code/data is copied here.
Assignment needs meaningful host-provided candidate costs; a mathematical optimum is not identity.

**Proofscape:** existing PDF-review/replay research stays in its own repo. Reuse its supported
extraction boundary if a later consumer needs PDFs; no new PDF detector is claimed by this package.

**Workspace Studio:** embed the framework-neutral component in a web host, or route a Studio
form to `applyStudioReview` with host-held dataset/claim/review objects. Recheck generation,
claim hash and expected head. A widget blueprint or status text alone does not execute this core.
Studio registration is discovery/design evidence, not a hosted installation or authenticated review.

**Kehitysatlas / knowledge inventory:** link the accepted commit and capabilities.json. A catalog
entry does not prove runtime installation or current real-data performance. Existing atlas data
can be stale; check GitHub before reuse.

**Agents:** the bundled workflow is a repository runbook, not an automatically installed plugin.
It grants no providers, credentials, tools, budget or approval authority.

Keep the core small. Add formats through adapters and consumer-owned methods; extract further
domain logic when another real consumer needs it. Preserve old fixture/results and review chains.
Use targeted checks for ordinary changes and the full package/frozen corpus for qualification.
Root repository landing rules apply independently.
