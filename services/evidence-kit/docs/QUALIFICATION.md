# Reuse pilot qualification

This is an authored synthetic mechanics baseline, not an independent real-document accuracy
claim. Source inputs and exact expected values/citation IDs were authored before evaluation
in `fixtures/suite.json`. They include both successful calculations and deliberate failures.

## Executed in the managed Linux workspace, Node 24.22.3

- `node --test services/evidence-kit/tests/*.test.mjs`: **14 passed**, 0 failed/skipped.
  Checks include getter rejection, strict JSON, immutable records, stale references, unit/value
  conflicts, ambiguous geometry, review concurrency/idempotency, hash-chain tampering, packet
  trust pins, source replay, old-review preservation and Studio source binding.
- `node services/evidence-kit/benchmark/run.mjs --check`: **18/18 expected contracts** matched.
  Five supported answers and 13 explicit abstentions; all supported answers and native citation
  IDs match the authored references. Coverage is 5/18, not a real-user success rate. Real-data
  qualification remains false and no comparable baseline is claimed. Actual timing and source,
  suite, evaluator and runtime hashes are in `benchmark/baseline.json`. Hash changes require a
  deliberate qualification update; the checker ignores incidental timing variation.
- Local `npm pack` archive installed **offline** into a separate project outside the source
  repository, with install scripts disabled. Public package exports computed the DXF area
  (12.00 m²), CSV total (30.30 EUR), exported and replayed a packet. No Stoa app, private Valmet
  code, runtime dependency installation or provider was required by the consumer.
- Real headless Chromium: drawing/table views, source inspection, confirmation, correction,
  Undo/Redo, packet download, changed-source unreviewed state, original-source replay/restore,
  conflict abstention and 390 px layout without horizontal overflow. **0 page errors and 0
  non-loopback requests.** The initial demo URL routing defect was found and repaired before
  this passing run. Browser acceptance is optional and repeatable with:

```sh
EVIDENCE_CHROMIUM=/path/to/chromium node services/evidence-kit/examples/browser-qa.mjs /tmp/evidence-browser
```

Provide an existing Playwright module with `EVIDENCE_PLAYWRIGHT_MODULE` if it is not installed
in the calling project. Neither the core nor its consumers install/download a browser.

- A real `stoa.evidence-packet/v1` envelope was generated by the existing public Stoa exporter
  using only the newly authored synthetic drawing. `migrate-stoa` preserved its old confirmation
  in history and produced a fresh unreviewed current claim; `replay` then verified the current
  extraction and result. Input/provenance pins are recorded in `PROVENANCE.json`.

## Not established

No licensed sponsor or private industrial source was fetched; no commercial data, training,
model/API call, production integration, physical calibration, authenticated review or signature
verification. No native macOS/iOS acceptance. The Studio widget shell/host bridge does not prove
that a hosted Studio runtime is executing this package. Catalog registration is discoverability.
There is no measured claim of development time saved: the reuse evidence is successful isolated
installation, two different consumers and explicit failure/replay behavior.
