# Chibi Lens — own trained candidate model v1

This is a **real, reproducible trained model**, but only a **synthetic numeric
observation-score baseline**. It is a small, standard-library Python logistic
classifier learned from 3,000 generated, labelled examples. It is **not** an
image/VLM model, does not inspect a DAT camera frame, and does not identify a
physical object. It uses no private videos, downloads, GPU or provider calls.

The five bounded features are `visual`, `text`, `shape`, `quality`, `recency`.
Appearance and OCR can be misleading (including near-duplicate hard negatives),
so high similarity is only a candidate. The trained threshold is calibrated
against **separate validation negatives**, and then evaluated on a third,
distribution-shifted synthetic holdout. The metrics explicitly report candidate
false positives, abstention and holdout degradation. The original synthetic
generator remains available for a heldout replay; these numbers are not a real
glasses recognition benchmark.

## Reproduce with Python 3.10+ (no third-party dependencies)

From this directory:

```sh
python3 -m unittest -v test_candidate_model.py
python3 candidate_model.py train --output trained-candidate-v1.json
python3 candidate_model.py evaluate --model trained-candidate-v1.json
```

The committed `trained-candidate-v1.json` is generated by the command above;
retraining with the same source/seed must produce identical bytes. The frozen
model records its seeds, sample counts, validation results and feature order.
The test suite guards model parsing, deterministic learning, synthetic split
provenance, an abstention threshold and the hard host/ML separation.

`candidate_proposal(model, scores)` returns `candidate` or `abstain` with a
probability. Its outputs **always** include `identityVerified: false` and
`actionAuthorized: false`, even for a perfect score. A real Chibi adapter must
still authenticate source/media receipts, scopes, active capture, immutable
host-held object IDs and fresh unique tag proofs through its own policy ports.
Never turn this suggestion score into host identity verification or permission.

## Next experiments (not implemented)

1. Build a consented/appropriately licensed real egocentric dataset with source
   digests and non-overlapping scenes, people, lighting and object IDs.
2. Replace the synthetic feature producer with on-device OCR/visual embeddings
   and an actual model trained/evaluated on that data; compare a frozen baseline.
3. Benchmark precision, recall, abstention, false verification **at the host**,
   and p50/p95 capture-to-audio latency under camera denial and disconnect.
4. Only then use an authorized, cost-bounded Verda GPU job for a larger VLM/LoRA
   study. Avoid calling a synthetic-score model a computer-vision model.

This code intentionally does not wire into the public Meta agent kernel or
private Chibi runtime. Current source ownership is `services/meta-spatial/ml/**`;
cross-service bindings belong to the shared integrator.
